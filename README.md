## 第二步：云服务器还是虚拟主机

雨云建站相关的产品线主要有两条：

**云服务器（RCS）**：KVM 虚拟化，独立公网 IPv4，有完整 root 权限，能自己装任何环境，可装 Linux / Windows，部分区域支持 macOS。适合要跑不止一个站点、要装 Docker、要折腾环境的人。

**虚拟主机（RVH）**：轻量、开箱即用，面板固定，主要支持宝塔和 EasyPanel，适合"我就想跑一个 WordPress 博客"的情况。它不用你自己装 LNMP，买完进面板就能建站，但也别指望在里面跑复杂应用。

判断标准很直白：一个站、只想省事 → 虚拟主机；多个站、要装东西、以后可能升级 → 云服务器。价格差不到一杯奶茶，但折腾程度差挺多。

## 第五步：从下单到网站能打开

流程本身不复杂，关键是别跳步：

1. **注册并绑定微信**，确认优惠券已经到账。下单前在页面上核对一下券是否被勾选。
2. **选机房和配置**。个人博客 1 核 1G 起步够用，WordPress 加几个插件、日常几百 PV 也不会卡；如果是企业官网或者要跑缓存、数据库，建议 2 核 2G 起。CPU 选型上，E5 系列便宜，EPYC 和 Xeon Gold 单核性能更好，同样配置价差体现在响应速度上。
3. **选系统镜像**。雨云提供预装宝塔、1Panel、Docker、WordPress 等环境的镜像，选预装版本能省掉一段命令行时间。想自己掌控就选纯净的 Ubuntu 或 Debian。
4. **登录面板建站**。宝塔里新建站点时可以直接勾选创建数据库，PHP 版本按程序要求选，WordPress 建议 7.4 以上。
5. **解析域名**。有自己域名的，在 DNS 里加 A 记录指向服务器公网 IP；只是测试的话，雨云提供免费二级域名，控制台里创建后按提示做 CNAME 或 A 解析即可。
6. **配 SSL**。宝塔里可以一键申请 Let's Encrypt 证书，也可以把自己域名服务商的证书粘进去。跨境站点常见做法是套一层 Cloudflare，源站证书用 Cloudflare 的 Origin Certificate。
7. **收紧防火墙**。面板端口不要长期对全网开放，改成白名单模式，只放行你自己的管理 IP；网站端口按需放行。这一步很多人省了，省出的麻烦通常在后面。

## 建站时容易踩的几个坑

**备案和过白是两道关。** 国内节点不是"买了就能用域名访问"，大陆网站和常用端口的 HTTP 业务需要先完成域名备案再过白。海外节点免备案，但也别把这条当成万能——如果你的用户全在国内，香港和洛杉矶的实际体验差别不小。

**流量用完会限速。** 不同机房的限速阈值不一样，有的是 1Mbps，有的是 5Mbps。流量本身是每月叠加、次月不清零的，可以按 20G/20 元、100G/100 元这类档位补，买之前先估一下自己站的图片和视频量。

**硬盘默认给得不多。** 云服务器的系统盘常见是 30GB，扩容按量计费，SSD 云盘大约 0.4 元/GB/月，机械或高效云盘约 0.1 元/GB/月。做图站、资源站的话，硬盘成本要算进预算，别只看月租。

**免费二级域名是用来测试的。** 它省事，但搜索引擎收录和品牌感都弱，正式站点还是建议自己注册域名。雨云控制台本身也提供域名注册入口。

**退款次数有限。** 7 天无理由退款每个账号只有 3 次额度，可以退，但别把它当成无限试错工具。

## 几个常见问题

**1 核 1G 真的能跑 WordPress 吗？**
能。加缓存插件、控制插件数量、图片压缩之后再上传，日常访问量的个人博客基本没问题。真正吃资源的是插件堆叠和数据库查询，不是 WordPress 本身。

**香港和洛杉矶怎么选？**
国内访客为主选香港，延迟明显更低；访客分散在海外、或者你要大带宽跑下载和资源分发，洛杉矶更划算。

**能不能先试用？**
可以。云服务器和游戏云支持 1 元试用一天，每款限 1 次。先用最低配跑一天，看延迟和面板是否顺手，再决定买哪一档。

**面板选宝塔还是 1Panel？**
宝塔功能全、教程多，出问题网上能搜到答案；1Panel 更轻、界面更简洁。虚拟主机是固定面板，云服务器才需要你自己决定。
